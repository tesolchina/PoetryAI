Current Problem

Revision Suggestion: Expand DDL Definition

Add to Section 1 (or create new subsection):

  • DDL's essence: Data-driven decision making based on language data patterns
  • Traditional DDL: Relatively "low-tech" approach using keyword matching, concordance lines, collocation searches
  • 21st Century DDL: Large language models use machine learning and neural networks to identify patterns from massive training data
  • Core principle remains: Both approaches are data-driven, but the technology and mechanisms differ fundamentally
Suggested Text Addition:
"While traditional DDL relies on explicit corpus queries and concordance searches—a relatively low-tech approach based on keyword matching—contemporary large language models represent a fundamentally different technological implementation of the same core principle: data-driven pattern recognition and application. The underlying logic of DDL—making language learning decisions based on patterns found in language data—remains constant, even as the mechanisms shift from explicit corpus consultation to implicit pattern learning through neural network training."

3. The "Eye-High, Hand-Low" Problem (眼高手低)

Current Problem

The introduction doesn't clearly articulate the specific problem that AI addresses in L2 creative writing.

Revision Suggestion: Explain the Core Problem

Add to Section 2 (or create new subsection):

The "Eye-High, Hand-Low" Problem:

  • Many L2 learners have ideas, emotions, and creative vision ("eye-high")
  • But lack language proficiency and text generation skills ("hand-low")
  • They can choose themes, topics, and forms, but cannot execute the actual writing
  • This gap prevents many potential learners from engaging in poetry writing
  • Traditional approaches: "Eye-high" is easier to train, but "hand-low" requires extensive practice
Suggested Text Addition:
"L2 creative writing pedagogy faces a persistent challenge that we term the 'eye-high, hand-low' problem: learners may possess rich ideas, emotions, and creative vision (high aesthetic awareness) but lack the linguistic proficiency and text generation skills necessary to transform these into written poetry (low execution capability). This gap between creative intention and linguistic execution creates a barrier that prevents many learners from engaging in poetry writing, despite having the motivation and conceptual understanding. While aesthetic awareness can be developed relatively quickly, linguistic execution requires extensive practice that many learners cannot access."

5. Connecting AI to DDL Principles

⚠️ This is the MOST CRITICAL Section

This connection must be made explicitly and convincingly to establish the study's legitimacy within DDL framework.

Revision Suggestion: Explicit DDL Connection

Add to Section 1 or create new subsection:

Why AI-Assisted Poetry Writing Counts as DDL:

  • Data-driven foundation: LLMs are trained on massive language data, learning patterns through machine learning and neural networks
  • Pattern-based generation: AI generates text by identifying and applying patterns learned from training data
  • Student input + AI patterns: The process combines student decisions (input) with AI's pattern-based text generation
  • Core principle: Both traditional DDL and AI-assisted DDL are data-driven, but use different mechanisms
  • Adjustability: Parameters (temperature, top-p) allow us to adjust how AI applies these patterns

Suggested Text Addition (CRITICAL):
"The question of whether AI-assisted creative writing constitutes DDL requires explicit examination. At its core, DDL represents data-driven decision making in language learning—making pedagogical choices based on patterns found in language data. Traditional DDL achieves this through explicit corpus consultation and keyword matching. Large language models achieve the same end through fundamentally different means: machine learning and neural networks that identify patterns from massive training datasets. When AI generates text based on student input, it applies these learned patterns—making the process inherently data-driven. The core principle remains constant: both approaches rely on language data patterns to inform language learning decisions. The difference lies not in the principle, but in the mechanism: explicit corpus queries versus implicit pattern application through neural network inference. Moreover, parameter configuration (temperature, top-p) provides a mechanism for adjusting how these patterns are applied, enabling pedagogical control over the data-driven process."

6. Clarifying "AI-Mediated Pattern Presentation"

Current Problem

The term "AI-mediated pattern presentation" is unclear. Readers don't understand what this means in concrete terms.

Revision Suggestion: Define the Term Clearly

Revise Section 1 where this term first appears:

  • Replace or supplement "AI-mediated pattern presentation" with clearer explanation
  • Explain: AI generates text outputs (poetry lines, phrases, corrections) based on patterns learned from training data
  • Clarify: This is the "presentation" of patterns—AI shows learners what patterns look like in actual text generation
  • Distinguish from traditional DDL: Traditional DDL shows patterns from existing corpus; AI generates new text that demonstrates patterns
Suggested Revision:
"Rather than learners searching corpora for patterns, AI proactively generates contextually relevant examples, corrections, or alternatives in real-time conversational exchanges. This shift represents a fundamental reconceptualization: where traditional DDL presents patterns from existing corpus data, AI-assisted DDL generates new text that demonstrates patterns learned from training data. This 'pattern presentation' occurs through actual text generation—AI creates poetry lines, phrases, or corrections that instantiate linguistic patterns, making them visible to learners through the creative writing process itself."
