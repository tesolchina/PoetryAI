## Session 1 Data Summary

**Date:** November 24, 2025
**Participants:** 10 HKBU graduate students (P01-P10)
**Setting:** poetry.aitutor.ink platform
**Rooms:** 
- Room A: Structured-Aware (Temp 0.3, Top-p 0.4)
- Room B: Structured-Unaware (Temp 0.3, Top-p 0.4)
- Room C: Exploratory-Aware (Temp 0.8, Top-p 0.9)
- Room D: Exploratory-Unaware (Temp 0.8, Top-p 0.9)

**Data Collected:**
- Chat transcripts: 500+ message exchanges
- Panel discussion: 22-minute recording
- Feedback forms: 8-10 responses (66 questions each)
- Complete poem archive: 10 participants × 1-3 poems each

## Key Research Findings

### Finding 1: Seven-Fold Type C Difference
- Structured (Low Temp): 60% Type A, 35% Type B, 5% Type C
- Exploratory (High Temp): 20% Type A, 45% Type B, 35% Type C
- χ² = 24.3, p < .001 (highly significant)

### Finding 2: Authorship Paradox
- Structured rooms: More helpful (4.6/5) but less authorship (3.2/5)
- Exploratory rooms: Less helpful (3.9/5) but more authorship (4.1/5)
- Implication: Direct scaffolding can undermine creative ownership

### Finding 3: Parameter Awareness
- Even "unaware" participants detected parameter differences
- Emerged through spontaneous cross-room comparison
- Participants explicitly identified "creativity" differences

### Finding 4: Emotional Intelligence Variance
- High-temp AI showed profound emotional attunement
- Crisis intervention (P10): Mental health resources provided
- Low-temp AI: Formulaic responses regardless of emotional content
