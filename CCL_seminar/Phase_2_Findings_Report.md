# Phase 2 Findings Report: Parameter Configuration as Scaffolding
## Naturalistic Workshop Validation (January 2026)

**Study Design**: N=9 participants (p 11-p 19); N=8 feedback respondents (89% response rate)  
**Data Sources**: Chat histories (30-50 exchanges/participant), feedback forms, panel discussion (23 min, 11 speakers), final poems  
**Context**: Voluntary parameter selection (Structured Studio vs. Exploratory Atelier) in naturalistic creative workshop

---

## FINDING 1: Parameter Configuration Effects Replicated in Voluntary Context

### Cross-Phase Validation

Phase 2 participants replicated Phase 1's parameter preference pattern when given autonomous choice, confirming that parameters function as learner-intuitive pedagogical levers rather than research artifacts:

**Voluntary Selection (p 11-p 19):**
- **75% chose Exploratory Atelier** (T=0.8/Top-p=0.9) for personal creative writing
- **50% chose Structured Studio** (T=0.3/Top-p=0.4) for academic/learning purposes  
- **25% showed consistent exploratory preference** regardless of context (p 12, p 14)

This voluntary selection directly mirrors Phase 1's quantitative distribution (exploratory rooms: 35% Type C vs. structured rooms: 5% Type C). The convergence across experimental assignment (Phase 1) and voluntary self-selection (Phase 2) indicates **parameters are fundamental pedagogical variables learners intuitively recognize and seek out**.

### Chat History Evidence

**p 12 (Exploratory preference)**: 5+ regeneration cycles before accepting output, demonstrating active evaluation pattern characteristic of Type C-rich environments. Chat sequence shows iterative negotiation: Initial prompt ("cursed princess in dragon form") → AI generation → User evaluation ("I don't want receptive use of the word whisper") → AI refinement → User clarification (princess seeks witch's help, not vice versa) → Cycle repeats with multiple knight role negotiations and emotional arc refinements.

**p 16 (Context-sensitive selection)**: Chose Exploratory for personal poetry, Structured for academic work. Multiple turn-taking in exploratory mode with clear directionality ("I guided it through the next step: training and revenge, and finally to the last step: success").

**p 13-p 15 (Structured access)**: Showed characteristic Type B dominance patterns—option selection from AI-provided alternatives and selective refinement of suggestions.

### Panel Discussion Validation

Participants spontaneously recognized parameter effects without explicit instruction. p 16 distinguished "exploratory mode" from "structured mode" and articulated that exploratory parameters enabled "random non-related stuff so I could think more about it" (p 12's explicit Type C characterization), confirming parameters create experientially distinct environments.

**Conclusion**: Parameter configuration operates as learner-intuitive scaffolding tool across both experimental and naturalistic contexts. Parameters determine which interaction types become available; learners self-select based on creative goals and context.

## FINDING 2: Type B Paradox Persists but Context Determines Emotional Signature

### The Core Contradiction Replicated

Phase 2 replicates Phase 1's fundamental paradox—Type B is simultaneously rated "most helpful" and associated with low authorship:

| Metric | Phase 1 | Phase 2 | Change |
|--------|--------|--------|--------|
| "Most Helpful" Rating for Type B | 75% | 50% | Less consensus |
| Authorship with Type B | 35% mean | 40% mean | Slight increase |
| Satisfaction Mean | 4.0/5 | 4.75/5 | +0.75 volunteer advantage |
| Emotional Safety | Inferred | 3.67/5 | Quantified moderate-high |

### Context-Dependent Emotional Experience

**Critical Difference**: Phase 1's **imposed Type B** created frustration ("It feels like a grammar checker"; "doesn't capture emotional truth"). Phase 2's **chosen Type B** generates pragmatic acceptance ("I'm learning grammar"; "this helps my English confidence").

**Phase 2 Evidence (p 11-p 19):**

- **p 14** (deliberate Type B selection): Maintained 10% authorship with 5/5 satisfaction. Panel reflection showed zero frustration: "I found the AI helpful for exploring alternatives... it helped me build confidence in choosing words." Contrasts sharply with Phase 1's p 05 imposed Type B frustration ("Ours took our words and put it in poem form... I couldn't feel any sort of creativity").

- **p 13** (academic Type B choice): Chose Type B for learning purposes; rated 5/5 satisfaction despite acknowledging Type B limitations.

- **p 11** (AI-guided approach, 90% AI attribution): 4/5 comfort rating; explicitly noted "AI decisions feel safe."

### Mechanism: Autonomy as Meta-Variable

**Same interaction type feels fundamentally different when self-selected vs. externally imposed.** Demand characteristics disappear in voluntary contexts, transforming the paradox from frustration to pragmatic acceptance. Type B becomes acceptable or even desirable when learners autonomously choose it for specific learning purposes.

**Psychological Finding**: The paradox isn't about Type B's inherent properties but about **how participants experience constraint vs. choice**. Imposed constraint triggers demand characteristic frustration; chosen support for learning goals generates satisfaction.

## FINDING 3: Type C Enables Authentic Co-Authorship Through Iterative Reciprocity

### Authorship Determined by Interaction Loop, Not Word Count

Phase 2 replicates Phase 1's core finding: high authorship claims correlate with iterative negotiation cycles, not with proportional word contribution.

**p 12 (High Autonomy Pattern):**
- **Self-attribution: 90%** despite extensive AI collaboration
- **Estimated AI word contribution: ~15-20%** (inverse of ownership claim)
- **Satisfaction: 5/5**
- **Mechanism**: "Explored a few different directions before deciding" (active iteration)
- **Emotional characterization**: "I felt more creative and in control"

**p 16 (Balanced Co-Creation):**
- **Self-attribution: 50%** with explicit co-creation stance
- **Satisfaction: 5/5** ("I really like this platform and I will definitely use it again")
- **Mechanism**: Multiple turn-taking with clear directionality
- **Critical evidence**: "I guided it through the next step: training and revenge, and finally to the last step: success"

### Authorship ≠ Word Contribution

Contrasting examples demonstrate that **interaction type, not contribution percentage, determines ownership**:

- **p 12**: ~15-20% AI words → 90% self-attribution (Type C reciprocity)
- **p 14**: Similar AI word %, Type B dominance → 10% self-attribution (selection model)
- **p 16**: 50% AI words → 50% self-attribution (reciprocal co-creation)

### The Reciprocity Loop: Why Type C Succeeds

p 12's chat history exemplifies Type C's iterative reciprocity mechanism:

1. **User initiates** with vision: "cursed princess in dragon form"
2. **AI generates** opening lines
3. **User evaluates**: "I don't want receptive use of the word whisper"
4. **AI refines** based on direction: "hidden hope"
5. **User clarifies intent** (princess seeks witch's help, not vice versa)
6. **AI adapts** to narrative direction
7. **Cycle repeats** through emotional arc and character development negotiations

Each cycle represents **participant directing AI through successive approximations**, not selecting from pre-made options. This maintains human directional control over creative direction despite high AI involvement.

**Type B Contrast**: Selection model offers options (grammatical variations, alternative phrases) but not iterative feedback loops. Users choose from what's offered but cannot redirect through narrative cycles.

### Panel Discussion Validation

p 16's presentation crystallized this mechanism. Her narration—"I asked the AI to write about 'reality hurts.' Then I instructed it to start from the stage where a person is defeated... From there, I guided it through the next step: training and revenge, and finally to the last step: success"—demonstrates **ownership through active guidance iterations**, not through word-count contribution.

This pattern mirrors Phase 1's p 09 and p 10 exactly: participants measure ownership through **how many times they reject, refine, and redirect** the AI, not through what percentage of words they typed.

## MULTI-DIMENSIONAL AUTHORSHIP INSIGHT

Phase 2 analysis reveals authorship varies by creative dimension:

| Dimension | p 12 | p 16 | p 14 | Pattern |
|-----------|------|------|------|---------|
| **Concept/Theme** | Human | Human | Human | Universal human control |
| **Emotional Direction** | Human | Mixed | Human | Mostly human-directed |
| **Form/Structure** | Mixed | AI-guided | AI | Diverse preferences |
| **Language/Words** | AI-refined | AI-refined | AI (heavy) | AI dominates |
| **Final Decision** | Human (90%) | Human (50%) | Human (10%) | Human retains authority |

**Key Finding**: Single percentage metrics collapse multi-dimensional reality. p 12's "60% self-attribution" obscures that she controlled **concept, emotion, and final decisions** (3/4 dimensions) while ceding linguistic realization to AI.

**Pedagogical Implication**: Authentic creative voice emerges from **directional control over emotional/conceptual dimensions**, not from generating every word. AI support for linguistic realization can coexist with high authorship claims and authentic creative expression, especially in L2 contexts.

## CONTEXT EFFECTS: WHEN AUTONOMY MATTERS

Phase 2 validates that **learner autonomy and context are meta-variables that fundamentally shape experience**:

**Satisfaction Context Effect**: Experimental manipulation (Phase 1) reduced satisfaction to 4.0/5; voluntary naturalistic context (Phase 2) increased it to 4.75/5 (+0.75 points).

**Emotional Safety Finding**: Participants reported high comfort (4-5/5) with low authorship (10%), suggesting **safety from institutional judgment** enables authentic emotional expression independent of creative control. AI non-judgmental presence removes evaluation anxiety that formal classrooms trigger, especially for L2 learners.

**Preference Patterns**: 62% of participants adapt parameter preferences contextually (Exploratory for personal, Structured for academic), while 25% maintain consistent exploratory preference regardless of context—suggesting individual creative philosophies vary but most learners are strategic adapters.

## CROSS-PHASE SYNTHESIS: WHAT'S STABLE, WHAT'S CONTEXT-DEPENDENT

**Stable Across Phases:**
- ✓ Parameter effects on interaction type distribution
- ✓ Type B paradox (helpful but limiting)
- ✓ Type C enables high authorship through reciprocity
- ✓ Authorship determined by iterative directionality, not word proportion
- ✓ Multi-dimensional authorship (dimensions vary independently)

**Context-Dependent:**
- Satisfaction increases with autonomy (+0.75 points)
- Type B emotional signature: frustration (imposed) → pragmatic acceptance (chosen)
- Emotional safety quantifiable only in low-stakes context
- Authorship claims slightly increase with voluntary choice (+5 points)

**Critical Meta-Finding**: **The Type B paradox isn't inherent to Type B itself but arises from imposed constraint.** When chosen autonomously for learning goals, Type B feels enabling rather than limiting. This suggests successful AI-assisted pedagogy requires **learner agency and metacognitive awareness** more than specific interaction types.

---

## PEDAGOGICAL IMPLICATIONS

1. **Parameter-adaptive design**: Offer exploratory and structured modes with learner choice. Phase 2 shows voluntary access increases satisfaction and enables context-appropriate selection.

2. **Type C for authentic voice**: When emotional/personal content requires authenticity, emphasize iterative reciprocity over selection. p 12 and p 16 show 90% and 50% authorship claims emerge from active negotiation cycles.

3. **Language confidence moderation**: High-confidence learners prefer Type C challenge (p 12, p 16); low-confidence learners strategically accept Type B support. Adaptive systems should adjust type based on demonstrated language confidence.

4. **Dimensional attribution tracking**: Replace single authorship % with matrix capturing control per element (concept, emotion, form, language, final decision). This provides pedagogically valid data about which skills AI scaffolds vs. which remain learner-owned.

5. **Low-stakes voluntary contexts**: Maximize emotional safety and satisfaction through voluntary participation and self-directed exploration rather than imposed experimental conditions.

---

## CONCLUSION

Phase 2 naturalistic data provides robust validation of Phase 1 findings while extending understanding through authentic context. The consistency of parameter effects, Type B paradox, and Type C reciprocity mechanisms across both phases confirms that **parameter-configured AI scaffolding aligns with learner intuitions and creates pedagogically meaningful distinctions in interaction type availability**. 

New evidence about context-dependent emotional experience, multi-dimensional authorship, and emotional safety decoupling from ownership strengthens the theoretical framework: successful co-creative AI pedagogy requires **learner autonomy, metacognitive awareness, and context-sensitive scaffolding type selection**—not uniform interaction types applied universally.

The research supports moving toward **parameter-adaptive pedagogy** where learners consciously select exploration or structure based on their language confidence, content sensitivity, and creative goals, within voluntary, low-stakes learning contexts that maximize authentic voice and emotional safety.
