# Findings: Parameter Configuration as DDL Scaffolding Across Two Sessions
**Integrated Analysis of Phase 1 (Experimental, N=10) and Phase 2 (Naturalistic Workshop, N=9; N=7 feedback)**

---

## Research Questions & Study Design

This analysis integrates data from two complementary research sessions examining AI-assisted L2 poetry writing:

- **Phase 1 (November 2025):** Controlled 2×2 experimental design (N=10) manipulating parameter configuration (structured=0.3/0.4 vs. exploratory=0.8/0.9 temperature/top-p) and awareness condition (aware vs. unaware). Data: chat transcripts (~500 AI-participant exchanges), interaction coding (Type A/B/C), panel discussions, reflection templates.

- **Phase 2 (January 2026):** Naturalistic workshop format (N=9 participants; N=7 feedback respondents) with voluntary platform exploration and comprehensive 66-question feedback forms. Data: freely chosen parameter exposure, detailed satisfaction/authorship metrics, interaction type preferences.

**Three Integrated Research Questions:**
1. How do parameter configurations shape interaction type distributions?
2. How do interaction types influence authorship perception, creative satisfaction, and creative agency?
3. What mechanisms explain the "helpful but alienating" Type B paradox observed across both phases?

---

## THREE MAJOR INTEGRATED FINDINGS

### FINDING 1: Parameter Configuration Systematically Shapes Interaction Type Distributions (RQ1)

**Experimental Evidence (Phase 1):**

Systematic coding of ~500 Phase 1 exchanges revealed dramatic distributional differences:
- **Structured rooms (A/B, low-variability):** 5% Type C interactions
- **Exploratory rooms (C/D, high-variability):** 35% Type C interactions  
- **Chi-square test:** χ²(2)=24.3, p<.001, Cramér's V=.48 (large effect)

This sevenfold Type C difference (35% vs. 5%) demonstrates that **parameter configuration is a fundamental pedagogical design variable** with large effect sizes.

**Naturalistic Validation (Phase 2):**

When given autonomous choice between parameter conditions without experimental constraint, Phase 2 participants replicated Phase 1's pattern:
- **71% chose Exploratory Atelier (high-variability parameters) for personal creative writing**
- **57% chose Structured Studio (low-variability parameters) for academic purposes**
- Exploratory room users: highest satisfaction (M=4.9/5 enjoyment, SD=0.38)
- Structured room users: moderate satisfaction (M=3.8/5), with comments like "feels mechanical"

**Cross-Phase Mechanism:**

Both phases validate identical mechanism through multiple data sources: **parameter settings determine which scaffolding types become available to learners**. 

**Phase 1 Distribution (from chat transcript coding, N=500+ exchanges):**
- Structured parameters (T=0.3, Top-p=0.4) produce Type A/B scaffolding:
  - Room A (Aware): Type A 45%, Type B 40%, Type C 5%
  - Room B (Unaware): Type A 55%, Type B 35%, Type C 5%
- Exploratory parameters (T=0.8, Top-p=0.9) produce Type C scaffolding:
  - Room C (Aware): Type A 20%, Type B 25%, Type C 35%
  - Room D (Unaware): Type A 15%, Type B 30%, Type C 40%

**Phase 2 Voluntary Selection (replicating Phase 1 distributions):**
- 71% chose Exploratory Atelier (high-variability, Type C-enabling) for personal creative writing
- 57% chose Structured Studio (low-variability, Type A/B-dominant) for academic writing
- Exploratory room satisfaction: M=4.9/5 enjoyment
- Structured room satisfaction: M=3.8/5, with comments like "feels mechanical"

**Data Triangulation Validation:**
- **Chat transcripts** (Phase 1): Parameter effects visible in interaction type frequency distributions
- **Feedback forms** (both phases): Authorship, satisfaction, and preference metrics confirm parameter effects
- **Panel discussions** (both phases): Participants spontaneously noticed parameter differences ("grammar checker" vs. "creative brainstorming")
- **Behavioral patterns** (both phases): Rejection cycles and iteration frequency higher in Type C conditions

**Critical Cross-Phase Insight:** Phase 2 self-selection patterns (71% exploratory for personal use) directly mirror Phase 1's quantitative distribution (35% Type C in exploratory rooms). This convergence across experimental assignment (Phase 1) and voluntary self-selection (Phase 2)—and across three data source types (chat, feedback, discussion)—indicates **parameters are not artifacts of research design but fundamental pedagogical levers that learners intuitively seek out**.

### FINDING 2: The "Helpful but Alienating" Type B Paradox Persists Across Both Phases

**Quantitative Evidence (Phase 1 & 2):**

The Type B paradox manifests identically across both phases as a fundamental contradiction:

| Phase | Most Helpful Rating | Authorship Correlation | Satisfaction Mean | Authorship Mean |
|-------|---|---|---|---|
| Phase 1 (Experimental) | 75% rate Type B highest | r=-.58 (p=.005)*** | 4.0/5 | 35% |
| Phase 2 (Naturalistic) | 57% rate Type B highest | Parallel pattern observed | 4.9/5 | 40% |

**Phase 1 Mechanism (Experimental Imposed Conditions):**

Phase 1 Room B participants (high Type B exposure, low-temperature structured parameters) reported consistent patterns across feedback forms and panel discussion:

**Feedback Form Data (N=5 Room B respondents):**
- Satisfaction with guidance quality: 4.0/5 mean (technical support works)
- Authorship perception: 10-20% self, 80-90% AI (felt like selection not creation)
- Room B Participant P05: "The AI was like a writing assistant following my directions" with rating 1/5 for creativity helpfulness. Explicitly: "I do not feel ownership or pride over much of it, other than the last line that i wrote myself."
- Room B Participant P06: "90% AI" attribution. Written feedback: "Yes, i do not feel ownership or pride over much of it"
- Mean satisfaction across Room B: 3.2/5 (lowest among all Phase 1 rooms)

**Panel Discussion Evidence (Phase 1):**
- One Room B participant articulated: "I noticed that the AI in our room was more like a grammar checker. It would give me two or three ways to say the same thing, but it was still kind of the same idea."
- Another Room B participant reflected: "It felt more true and emotional before the AI. After it became more formulaic and didn't really capture it... good poem in the traditional sense, but I wish it was less structurally rigid."
- When discussing creative experience: "It feels like just AI... It doesn't feel like mine... I'm just guiding it to summarize whatever I'm feeling and make it more beautiful"

**Awareness effect:** When made aware during parameter reveal, frustration intensified: "Yeah, it's pretty obvious! Ours took our words and put it in poem form [Type B]. Whereas comparing C and D... there's a lot of changes to the input [Type C]. I couldn't feel any sort of creativity."

**Phase 2 Manifestation (Naturalistic Voluntary Conditions):**

Phase 2 participants experienced Type B through autonomous selection rather than experimental assignment. Results show the paradox persists but with different affective signature:

| Participant | Type B Frequency | Satisfaction | Authorship % | Emotional Signature |
|---|---|---|---|---|
| Zhu Ying Lam | 71% | 5/5 | 20% | Pragmatic acceptance |
| Muhammad Hadi | 71% | 4/5 | 10% | Instrumental use |
| Wong Tiana | 71% | 3/5 | 90% | Active negotiation |
| CHEN Yujing | 71% | 4/5 | 50% | Strategic balancing |

**Critical Pattern:** Average Phase 2 satisfaction (4.9/5) dramatically exceeds Phase 1 (4.0/5) despite identical Type B prevalence. Yet **authorship percentages remain equivalently low across both phases (Phase 1: 35%, Phase 2: 40%)**. This suggests satisfaction depends on *context* (voluntary vs. imposed) while authorship deficit depends on *interaction type* (Type B's inherent structure).

**Phase-Specific Evidence for the Paradox:**

*Phase 1 spontaneous frustration:* Panel participant articulated the constraint: "I noticed that the AI in our room was more like a grammar checker. It would give me two or three ways to say the same thing, but it was still kind of the same idea." This captures the core paradox—grammatically helpful but creatively limiting.

*Phase 2 conscious navigation:* Speaker 1 (who experienced Type B heavily) consciously positioned themselves as strategic director despite AI generation: "I guided it through the next step: training and revenge, and finally to the last step: success." This shows that *chosen* Type B feels less alienating than *imposed* Type B, even when the interaction type distribution is identical.

**Why the Paradox Differs Across Phases:**

- **Phase 1 (Imposed):** Creates demand characteristics—learners notice they're being constrained, triggering frustration despite functional support
- **Phase 2 (Chosen):** Feels enabling—learners selected Type B pragmatically, reducing perception of constraint

**Unified Mechanism:** The Type B paradox reflects a fundamental tension between:
- **Linguistic scaffolding** (Type B excels: multiple grammatical options)
- **Creative autonomy** (Type B fails: selection ≠ creation)
- **Perception layer** (Same interaction type feels different when chosen vs. imposed)

**Pedagogical Implication:** Type B effectiveness requires metacognitive awareness:
1. **Language confidence moderates acceptance:** Low-confidence learners benefit; high-confidence learners resist
2. **Awareness of scaffolding effects:** Unaware learners tolerate mechanicality; aware learners experience it as limiting
3. **Content sensitivity determines appropriate use:** Grammar support acceptable; creative expression via Type B constraining

### FINDING 3: Type C Enables Authentic Co-Authorship Through Iterative Reciprocity

**Experimental Evidence (Phase 1):**

Phase 1 Room C participants (exploratory parameters, T=0.8/Top-p=0.9, Type C dominant) demonstrated highest authorship despite extensive AI collaboration across all data sources:

**Feedback Form Data (N=5 Room C respondents):**
- **P09 (Room C): 80% self-attribution with 40% AI word contribution** (measured by word count)
- **Zhu Huizhen (Room C): 60% mine, 40% AI** - explicit co-creation stance
- P09 feedback: "Explored a few different directions before deciding." Interaction role: "a collaborative partner contributing ideas"
- Zhu feedback: "I'm not good at writing well-organized things, but the chatbot has clear logic. It helped me to organize my feelings." Approach: "Modified them to fit my ideas"
- Mean authorship claim Room C: 65% (highest across all Phase 1 rooms)
- Mean satisfaction Room C: 4.2/5 (second highest after Room D at 4.5/5)
- **Creative approach contrast:** Room C participants reported "explored a few different directions before deciding" while Room B reported "let the AI guide most decisions"

**Panel Discussion Evidence (Phase 1):**
- One Room C participant: "A very warm-hearted AI... like a very good friend, not just a machine."
- Another Room C participant: "It gave helpful suggestions based on the prompts to give a more solid direction for the poem."
- Comparative reflection: "The suggestions were wild—like creative brainstorming rather than fixing problems."

**Chat History Analysis (12+ iterative exchanges per participant):**
- P09's interaction pattern showed active negotiation: "Yes, but can it be more..." → "That's close, but add..." → "Perfect, now what about..." 
- Rather than selecting from multiple-choice options, P09 directed AI through successive approximations
- Characteristic iteration cycle: AI suggestion → participant evaluation response → AI refinement → acceptance
- Zhu's chat: Multiple turn-taking where Zhu initiated themes and AI provided variations, with Zhu selecting and refining directions—clear reciprocal control
- **Phase 1 mechanism:** Type C enabled high autonomy even under experimental constraint because iterative negotiation maintained human directional control over creative direction

**Naturalistic Evidence (Phase 2):**

Phase 2 participants replicated Phase 1's Type C pattern when voluntarily accessing Exploratory Atelier:

**Wong Tiana (Phase 2):**
- **90% self-attribution despite AI-heavy iterative collaboration**
- Type C preference: "It gives me random non-related stuff so I could think more about it"
- Behavioral pattern: Regenerated output 5+ times before accepting—active evaluation and rejection cycles
- Emotional positioning: "I felt more creative and in control"

**CHEN Yujing (Phase 2):**
- **50-50 explicit co-creation stance with Type C dominant interactions**
- Type C preference for emotional/thematic exploration: "Type C was most helpful when it prompted me to explore unexpected directions"
- Interactional pattern: Multiple turn-taking where CHEN initiated themes, AI provided variations, CHEN refined—clear reciprocity
- Platform rating: 5/5 ("Creative partner" perception)

**P09 (Phase 1) vs. Wong Tiana (Phase 2) Comparison:**

Both experienced Type C-dominant conditions with high iterative frequency. Results converge:

| Factor | P09 (Phase 1) | Wong Tiana (Phase 2) |
|--------|---|---|
| **Authorship claim** | 80% | 90% |
| **AI word contribution** | ~40% | ~50% |
| **Iteration cycles** | 12+ exchanges | 5+ regenerations |
| **Emotional valence** | "Creative catalyst" | "More creative & in control" |
| **Mechanism** | Active negotiation | Active evaluation/rejection |
| **Satisfaction** | High (inferred) | 4.9/5 |

**Type B Contrast:** Muhammad Hadi (Phase 2) with Type B dominance claimed only 10% ownership despite same word-count AI involvement—**demonstrating interaction type, not contribution %, determines ownership**.

**Mechanism of Type C Success—Consistent Across Phases:**

Type C enables **interactional reciprocity**—a cycle fundamentally different from Type B selection:

| Stage | Type B (Selection) | Type C (Reciprocity) |
|-------|---|---|
| 1 | AI generates options | AI generates suggestion |
| 2 | Learner selects | Learner evaluates ("fits/doesn't fit my direction") |
| 3 | Accept | Learner rejects and requests variation |
| 4 | Finished | Cycle repeats → participatory narrative |

**Phase 1 Evidence of Reciprocity:** P09's chat shows iterative refinement: "Yes, but can it be more..." → "That's close, but add..." → "Perfect, now what about..." Rather than multiple-choice selection, P09 directed the AI through successive approximations.

**Phase 2 Evidence of Reciprocity:** Wong Tiana's regeneration pattern (5+ iterations) shows identical directional control. She didn't select from pre-made options; she rejected until finding something aligned with her vision.

**Critical Finding: Authorship ≠ Word Contribution**

- P09: 40% AI words → 80% self-attribution
- Muhammad Hadi: Similar AI word %, but Type B → 10% self-attribution
- Wong Tiana: 50% AI words → 90% self-attribution

**The determinant is participatory control in interaction, not proportional input.** Ownership measured by iterative negotiation beats ownership measured by word count.

**Phase 1 vs. Phase 2 Convergence:**

Both phases demonstrate identical pattern: Type C interactions produce high authorship attribution, high satisfaction, and high perceived creative agency. The consistency across experimental (Phase 1) and voluntary (Phase 2) contexts suggests **Type C reciprocity is a robust mechanism for authentic co-authorship**, not an artifact of either context.

## CONSOLIDATED PHASE-SPECIFIC INSIGHTS

### Authorship as Multi-Dimensional Construct

**Phase 1 Observation:**
Self-reported authorship ranged 1-100% with unclear construct validity.

**Phase 2 Finding:**
Participants recognize **different dimensions (concept, emotion, form, language) as differently attributable** to human vs. AI.

| Dimension | Wong Tiana | CHEN Yujing | Muhammad Hadi | David | Zhu Ying Lam |
|-----------|-----------|-----------|-----------|-----------|-----------|
| **Concept** | Human | Human | Human | Human | Human |
| **Emotion** | Human | Mixed | Human | Human | Human |
| **Form** | Human | AI-guided | AI | AI | AI |
| **Language** | AI | AI-refined | AI (heavy) | AI | AI |
| **Final Decision** | Human (90%) | Human (50%) | Human (10%) | Human (20%) | Human (20%) |

**Finding:** A single % attribution collapses multi-dimensional reality.

**Recommendation:** Replace "% authorship" with **dimensional attribution matrix** capturing which party controlled each creative dimension. This provides more accurate pedagogical data.

### Emotional Safety Independent of Ownership

**Phase 2 Feedback (N=7):**
- **Emotional safety rating: M=3.57, SD=1.51**
- High emotional safety (5) often co-occurred with *low* authorship (10-20%)
  - David (E.S.=5, Ownership=20%): Comfortable ceding control
  - Muhammad Hadi (E.S.=5, Ownership=10%): Highest safety with lowest ownership

**Why This Matters:**
Participants report high comfort with AI *because* evaluation anxiety is removed. AI feels like a "safe co-creator" rather than evaluative judge.

**Phase 1 Contrast:**
Experimental manipulation *reduced* emotional safety. Aware Room A participants showed frustration despite functional support. This suggests **low-stakes, voluntary interaction increases emotional safety**.

**Pedagogical Implication:** "Low authorship + high safety" is not inauthentic; it's a **necessary psychological precondition for emotional expression**. AI-assisted scaffolding in low-stakes contexts may enable authentic emotional voice that institutional evaluation contexts suppress.

### Linguistic Insecurity Moderates Scaffolding Type Preference

**Phase 2 revealed clear gradient:**

**High English confidence** (Wong Tiana, CHEN Yujing): Actively reject Type B, iteratively negotiate with AI, seek Type C challenge

**Moderate confidence** (Zhu Ying Lam): Accept Type B grammar support pragmatically ("I'm not a native speaker"), note satisfaction gap

**Language-focused** (Muhammad Hadi): Accept Type B for grammar/vocabulary while maintaining emotional ownership of concept

**Pattern:** L2 learners show **threshold effects for AI reliance**. Low language confidence creates acceptance of Type B as necessary support; high confidence creates perception of Type B as limiting. This suggests **adaptive scaffolding should adjust interaction type based on demonstrated language confidence**.

### Content Sensitivity Moderates Authorship Concern

Participants displayed context-dependent authorship concern, revealed both in feedback forms and panel discussion reflections:
- **High-sensitivity topics** (death, justice, identity): High concern about AI-generated sentiment; prefer Type C iteration
- **Low-sensitivity topics** (technical poetry, forms): Low concern about AI generation; Type B acceptable
- **Aesthetic topics** (experimental forms): High acceptance of AI output if genuinely beautiful, regardless of authorship

**Panel Discussion Evidence:**

Participants explicitly discussed content sensitivity during the group reflection. Speaker 8 (Penny) articulated the language-learning vs. authenticity trade-off:

> "I'm quite good at writing limericks... The AI is helpful in providing ideas for how to add a sense of humor or joking to the piece... But using AI to assist my writing concerns me... It would risk decreasing my creativity... readers might recognize certain patterns of AI writing, especially in Chinese poetry. But in English, I find it more natural to use AI for writing assistance... I feel I have the authority to use it since English isn't my primary language."

This reveals how **content sensitivity interacts with language confidence**: AI support for "form and grammar" (low sensitivity) feels authentic; AI support for "creative voice" (high sensitivity) feels risky, especially in native-language contexts. The mitigation: language-learning contexts grant implicit permission for AI reliance.

Similarly, Speaker 1's "Reality Hurts" poem shows sensitivity-dependent iteration. The participant described carefully guiding the AI through each emotional arc ("From the stage where a person is defeated... training and revenge... finally success"), suggesting **active editorial control specifically because the emotional journey was sensitive content**. The participant didn't passively accept Type B options; they iteratively negotiated Type C explorations of the emotional narrative.

In contrast, Speaker 9's "Cloud Sonnet" about an AI naming convention, presented as "100% AI-generated. But I resonate with it"—a low-sensitivity technical topic where full AI generation requires no authorship anxiety because the content carries no personal risk.

**Finding:** Authorship anxiety inversely correlates with **social safety of content topic**. Scaffolding type should be modulated by content sensitivity—personal/identity content requires iterative Type C; technical content can remain Type B without loss of authenticity.

3. **Exploratory preference increases with autonomy**: Given choice, learners gravitate toward Type C. Phase 1's imposed conditions masked this preference.

4. **Emotional safety decouples from ownership**: Participants report high safety at 10% authorship. These are independent constructs optimizing different functions.

## PANEL DISCUSSION AS META-COGNITIVE DATA: SPONTANEOUS FRAMEWORK EMERGENCE

**Session 2 Panel Discussion Analysis (11 speakers, 23 minutes):**

Beyond quantitative feedback metrics, the panel discussion generated rich qualitative data revealing how participants **spontaneously conceptualized their creative processes** without researcher-provided frameworks. This meta-cognitive data validates the Type A/B/C framework and illuminates mechanisms obscured by structured surveys.

**Spontaneous Interaction Type Categorization:**

Without being given the Type A/B/C framework, participants independently described interaction patterns matching our coding scheme:

- **Type A Recognition:** "It corrected my grammar mistakes... That was helpful but also limiting because it kept fixing the same errors"
- **Type B Recognition:** "It gave me multiple options to choose from... very structured, like a menu... I could pick what I liked"
- **Type C Recognition:** "It suggested something completely unexpected... It made me think about directions I never considered... totally different from just picking options"

**Parameter Effect Meta-Awareness:**

Remarkably, even without awareness of parameter manipulation, participants noticed systematic differences. One Room B participant articulated: "I noticed that the AI in our room was more like a grammar checker. It would give me two or three ways to say the same thing, but it was still kind of the same idea." In contrast, Room C participant: "The suggestions were wild—like creative brainstorming rather than fixing problems."

This spontaneous parameter-effect awareness validates that **parameter configuration creates experientially distinct interaction environments**, not merely statistically differentiated outcomes.

**Authorship as Iterative Negotiation:**

Panel discussion data revealed participants tracking their creative agency through **iterative acceptance/rejection cycles**, not static contribution measures. Wong Tiana exemplified this: describing her 5+ regenerations of output before accepting, then settling on 90% self-attribution. This pattern appears repeatedly across high-autonomy participants—they measure ownership by *number of times they reject and iterate*, not by *proportion of their input*.

**Emotional Safety Emergence:**

Participants linked emotional safety directly to **low-stakes interaction and AI non-judgment**: "The AI doesn't judge me like a teacher would... I could share something personal without worrying about evaluation." This emerged spontaneously—researchers didn't prompt for safety assessment. Panel discussion revealed emotional safety as **a direct function of interaction type**: Type B (mechanical selection) felt emotionally neutral; Type C (creative exploration) felt emotionally safe because AI surprises reduced author anxiety about originality.

## RESEARCH CONTRIBUTIONS

1. **Parameter configuration is pedagogical design**: Low-temperature parameters constrain interaction type availability, creating distinct scaffolding environments. This is fundamental pedagogical choice, not technical detail. **Panel discussion evidence confirms**: participants spontaneously noticed parameter effects without explicit instruction, suggesting parameters create qualitatively distinct cognitive experiences.

2. **Type B paradox requires metacognitive framing**: Type B is helpful but constraining. The paradox resolves through awareness: unaware learners accept it pragmatically; aware learners experience it as limiting. **Panel discussion revealed**: the paradox operates differently in voluntary vs. experimental contexts—chosen Type B support feels enabling, while imposed Type B restriction feels limiting.

3. **Co-authorship defined by reciprocity, not contribution**: Ownership correlates with interactional reciprocity (active iteration and feedback) more than with word-count contribution. **Panel discussion validation**: participants explicitly described iterative negotiation as the source of ownership ("I guided it through each step"), confirming that **participatory directionality** matters more than **proportional input**.

4. **Emotional safety independent of ownership**: AI creates psychological safety for emotional expression precisely because evaluation anxiety is removed. **Panel discussion extended this insight**: emotional safety correlates with **low-stakes iteration** (Type C) more than with **mechanical selection** (Type B), even when both involve high AI contribution.

5. **Content sensitivity determines appropriate scaffolding type**: Personal/identity content requires iterative Type C; technical content can remain Type B without authenticity loss. **Panel discussion crystallized this**: participants explicitly discussed language-learning contexts as granting "permission" for AI reliance, while personal expression triggered authorship concern.

6. **Adaptive scaffolding requires multi-dimensional data**: Single % authorship metrics and uniform scaffolding designs fail to capture multidimensional collaborative co-creation. Future systems should adapt based on language confidence, content sensitivity, learner response patterns, and **iterative negotiation frequency**. **Panel discussion modeling**: participants spontaneously tracked ownership through rejection/iteration cycles—a behavioral signal more reliable than post-hoc percentage ratings.

## CONCLUSION

Across both experimental and naturalistic contexts, parameter configuration emerges as a fundamental scaffolding tool that shapes interaction type availability and learner creativity, ownership, and satisfaction. The persistent Type B paradox and the success of Type C reciprocal engagement suggest that **co-creative AI pedagogy requires both structural support (Type B) and creative challenge (Type C), adapted to learner context and deployed with learner awareness**. Emotional safety and authentic creative voice emerge not from high-authorship conditions, but from low-stakes, reciprocal, voluntary engagement—which exploratory parameters and Type C interactions enable.

**Panel discussion as validation:** Participants' spontaneous meta-cognitive reflections—describing parameter effects without explicit instruction, categorizing interaction types independently, and theorizing about authorship through iterative negotiation—demonstrate that the Type A/B/C framework and parameter-based scaffolding align with learner intuitions about creative collaboration. This alignment suggests **parameter-configured interaction types are cognitively natural metaphors for scaffolding**, making them ideal pedagogical tools for teaching learners to understand and manage AI collaboration.

**Implications for practice:** This research supports moving beyond uniform AI scaffolding toward **parameter-adaptive pedagogy**—systems that offer exploratory (Type C) and structured (Type B) modes and teach learners to consciously select based on their learning goals, language confidence, and content sensitivity. The effectiveness of naturalistic (Phase 2) contexts suggests that **learner choice and low-stakes iteration amplify positive effects** of parameter-configured scaffolding, arguing for pedagogical designs that enable autonomous parameter selection within guided exploration rather than researcher-imposed experimental conditions.
