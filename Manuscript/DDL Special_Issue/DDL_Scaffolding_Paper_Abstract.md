# Abstract

This study addresses Crosthwaite’s (2023) challenge by testing how generative AI parameter configuration shapes L2 creative writing outcomes. In a 2×2 design (N=10; target N=20), we manipulated temperature/top-p (structured 0.3/0.4 vs. exploratory 0.8/0.9) and parameter awareness while Hong Kong university students composed poetry with AI support. Exploratory settings produced about seven times more Type C “surprise harvest” interactions (35% vs. 5%, p<.001). Although 75% preferred Type B “exemplar giving,” higher Type B frequency correlated with lower authorship perception (r=-.58). Findings suggest parameter literacy enables AI to serve as adaptive scaffolding rather than pattern-enforcing support.

**Keywords:** Data-Driven Learning; generative AI; parameter configuration; adaptive scaffolding; L2 creative writing
